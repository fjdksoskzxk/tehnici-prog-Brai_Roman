# Rezolvare laborator Python web

Proiectul rezolvă exercițiile 1-50 și bonusul din laboratorul despre importuri, metode, funcții și module web.

## Instalare

```powershell
python -m pip install -r requirements.txt
```

## Rulare

```powershell
python part1_imports.py
python part2_methods.py
python part3_functions.py
python part4_modules.py
python webtools.py
python main.py https://cybercor.org
```

Ultima comandă creează `report.json` și `report.csv`. Valorile depind de starea site-ului în momentul rulării.

## Corespondența exercițiilor

- `part1_imports.py`: exercițiile 1-8
- `part2_methods.py`: exercițiile 9-20
- `part3_functions.py`: exercițiile 21-34
- `part4_modules.py`: exercițiile 35-43
- `webtools.py` și `main.py`: exercițiile 44-50

Comentariile din cod conțin explicațiile cerute. Toate cererile au timeout, iar cererile repetate sunt separate de pauze de o secundă. Antetul `User-Agent` este configurat cu identificatorul `Brai-Roman-SI-263`; completați numele arhivei conform cerinței profesorului.
