# Laboratorul 13 - with și pytest

Proiectul conține Lucrarea A în `arsenal/forensics` și Lucrarea B în `reparare`.

Rulare unealtă:

`python -m arsenal.forensics.amprente arsenal/forensics/probe`

Teste Lucrarea A:

`python -m pytest -q arsenal/forensics/test_amprente.py`

Teste Lucrarea B, din folderul `reparare`:

`python -m pytest -q`
